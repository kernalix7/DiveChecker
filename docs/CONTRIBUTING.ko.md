# DiveChecker 기여 가이드

[English](../CONTRIBUTING.md) | **한국어**

DiveChecker에 기여해 주셔서 감사합니다. 이 가이드로 시작해 보세요.

## 사전 요구사항

- Flutter SDK 3.10.4+ / Dart 3.10+
- Pico SDK 2.2.0 (펌웨어 작업 시)
- CMake 3.13+ (펌웨어 작업 시)
- Android Studio / Xcode (모바일 빌드 시)
- Python 3.9+ (사이트 검증 스크립트 시)

## 빌드

### 앱

```bash
git clone https://github.com/kernalix7/DiveChecker.git
cd DiveChecker/_0_DiveChecker-APP
flutter pub get
flutter gen-l10n
flutter run
```

### 펌웨어

```bash
cd 0_Pico2-Firmware/Divechecker
mkdir -p build && cd build
cmake .. && make -j$(nproc)
# 결과물: Divechecker.uf2 — Pico2 BOOTSEL에 드래그앤드롭
```

### 마케팅 사이트 (정적)

```bash
python3 -m http.server -d website 8000
# → http://localhost:8000
```

## 테스트

```bash
# 앱
cd _0_DiveChecker-APP
flutter test
flutter analyze --no-fatal-infos

# 사이트 (HTML 파서 + i18n 키 해석)
python3 -c "import html.parser; [html.parser.HTMLParser().feed(open(f).read()) for f in ['website/index.html','website/vent.html','website/faq.html','website/support.html','website/disclaimer.html','website/privacy.html']]"
```

## 작업 흐름

1. 저장소를 **Fork** 합니다
2. **기능 브랜치**를 생성합니다 (`git checkout -b feat/my-feature`)
3. **conventional commits** 스타일로 커밋합니다
4. **Pull Request**를 생성합니다

## PR 체크리스트

PR 제출 전 다음을 확인하세요:

- [ ] `flutter test` 통과
- [ ] `flutter analyze --no-fatal-infos` 오류 0개
- [ ] 펌웨어 변경: `cmake .. && make -j$(nproc)` 빌드 + 플래시 스모크 테스트 완료
- [ ] 사이트 변경: HTML 파싱, i18n 키 해석, EN HTML 기본값에 한국어 박힘 없음
- [ ] 문서 갱신 (CHANGELOG + EN 변경 시 docs/*.ko.md 미러)
- [ ] 하드코딩된 자격증명/비밀 없음
- [ ] 커밋/PR 본문에 AI 흔적 (`Co-Authored-By`, `Generated by` 등) 없음

## 커밋 규칙

[Conventional Commits](https://www.conventionalcommits.org/) 사용:

| Prefix | 용도 |
|--------|------|
| `feat` | 새 기능 |
| `fix` | 버그 수정 |
| `refactor` | 동작 변경 없는 내부 구조 개선 |
| `docs` | 문서만 |
| `test` | 테스트만 |
| `chore` | 빌드 / 도구 / CI |
| `ci` | CI 워크플로우 변경 |

Scope 표기: `feat(app):`, `feat(firmware):`, `feat(website):`, `fix(cad):` 등.
