How to Use

Step-by-step equalization practice using the sensor.

1. Preparation

Place the air inlet on top of the device snugly against one nostril and block the other nostril.

2. Practice

Build pressure using an equalization technique such as Valsalva or Frenzel.

3. Observe

Observe the pressure intensity and duration on the real-time graph.

4. Repeat

Repeat practice aiming for consistent pressure and uniform waveforms.

03

Equalization Technique Guide

Knowing the graph pattern of each technique helps you accurately identify your equalization.

Basic

Valsalva

Valsalva

A technique that pushes air using abdominal/chest pressure while pinching the nose

Graph Pattern

A slowly rising rounded curve. Slow rise/fall with a wide peak.

Excessive force risks eardrum damage. Stop immediately when an overpressure warning appears.

Intermediate

Frenzel

Frenzel

A technique that compresses air by pushing the tongue root up against the palate

Graph Pattern

A fast, sharp spike. Rapid rise/fall with a narrow peak.

Try practicing with a "K" or "T" tongue motion.

Advanced

Mouthfill

Mouthfill

A technique that equalizes using only the air in the mouth with the glottis closed

Graph Pattern

An initially high peak followed by progressively decreasing consecutive peaks. Pressure drops as the air in the mouth depletes.

Advanced

Hands-free / BTV

Hands-free

Voluntary opening of the Eustachian tube. Equalization without pinching the nose.

Graph Pattern

Very subtle pressure changes. Small peaks but a consistent pattern.

04

How to Read Peak Analysis

Objectively evaluate equalization quality with four metrics.

Rhythm Score

Consistency of peak intervals. Based on coefficient of variation (CV) — higher means more regular equalization.

Pressure Score

Uniformity of peak intensity. Evaluates whether you equalize with consistent force each time.

Technique Score

Rise/fall time and peak width analysis. Sharp peaks = closer to Frenzel.

Fatigue Index

Pressure decline trend in the latter half of the session. High value indicates accumulating muscle fatigue.

Overall Grade

SPerfect
AExcellent
BGood
CAverage
DPoor
FInsufficient

Calculated as a weighted average of the four metrics. Keep practicing to improve your grade!

05

Care & Cleaning

Clean regularly to maintain sensor accuracy and hygiene.

Sensor Inlet Cleaning

Gently remove debris from the air inlet using a thin cotton swab or the dedicated cleaning tool available as an optional accessory.

Precautions

  • Do not wash directly with water or liquids
  • Do not poke the sensor hole with sharp tools
  • Do not spray compressed air directly

Storage

Store in a dry, cool place after use. Avoid direct sunlight and high-temperature environments.

The dedicated cleaning tool and Lightning adapter are available for separate purchase as optional accessories.

06

Calibration

The process of setting the current atmospheric pressure as the 0 hPa baseline. Recommended before every session.

Calibration Process

  1. Remove your mouth/nose from the sensor and leave it in its natural state
  2. Tap the "Calibration" button in the app
  3. Atmospheric pressure samples are collected for 3 seconds
  4. The average value is automatically set as the baseline

Always recalibrate after changing altitude or location. Atmospheric pressure changes affect measurement values.

08

Troubleshooting

  • Make sure you are using a data cable, not a charge-only cable
  • Try connecting to a different USB port
  • Disconnect and reconnect the cable
  • Android: Make sure USB OTG setting is enabled
  • iOS: Only USB-C iPhone 15 or later / USB-C iPad supported (Lightning requires an adapter)
  • Run calibration again
  • Check if the sensor hole is free of debris
  • Close and restart the app
  • Run calibration again
  • Check if moisture has entered the sensor
  • After rapid temperature changes, wait 10 minutes to stabilize before use
  • Check if the cable is properly connected
  • Test by connecting to a different device
  • If the problem persists, contact customer support
